❓ Pre-Shift Email Briefing Help

Getting Started

This tool helps you create daily shift briefing emails for your team.

Step-by-Step Guide

  1. Select Date: Choose the date for the briefing
  2. Select Day & Shift: Choose the day of the week and shift type (Day/Night)
  3. Greeting Comment (Optional): Add any additional comments after the automatic greeting
  4. Tasks: Tasks are automatically pulled from Settings based on the selected day and shift
  5. Extra Tasks: Add any additional tasks (one per line)
  6. Crewing Status: Select the crewing status for each vehicle (Fully/Single/Uncrewed)
  7. Crewing Notes: Add any additional crewing notes
  8. Road Closures:
    • Click "Plan Road Closures" to schedule future closures
    • Click "Add Road Closure" for last-minute closures
  9. Duty Manager: Select the duty manager from the dropdown
  10. Fleet Movements: Enter fleet movements or leave empty for default message
  11. Other: Add any other notes or leave empty for default message
  12. Copy Email: Click to copy the formatted email to your clipboard, then paste into Outlook

Tips

  • Configure recurring tasks in Settings → Tasks by Day
  • Plan road closures in advance using the "Plan Road Closures" feature
  • The email preview updates automatically as you type
  • All data is saved automatically to the cloud

❓ WOM Comms Help

Getting Started

This tool helps you create formatted communication emails for area-wide distribution.

Step-by-Step Guide

  1. Select Date: Choose the date - this will automatically update the title
  2. Title: The title is auto-filled with the date, but you can edit it if needed
  3. Introduction: Enter the introduction text (will appear in bold)
  4. Sections:
    • Click "Add Section" to create a new section
    • Enter a section title and content
    • Content supports HTML formatting
    • Remove sections using the "Remove" button
  5. Attachments: Enter attachment names (one per line) - they will appear as bullet points
  6. Update Preview: Click to refresh the preview if needed
  7. Copy Email: Click to copy the formatted email to your clipboard, then paste into Outlook

Tips

  • You can add as many sections as needed
  • Section content supports HTML - use it for formatting, links, etc.
  • The preview updates automatically as you type
  • The Staff Committee feedback button is automatically included at the bottom
